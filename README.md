# Installation 
1. Install Java and Set JAVA_HOME env variable
2. Install Maven and Set MVN_HOME env variable
3. Install Eclipse IDE
4. Install Cucumber plugin in your Eclipse

# Getting Started
1. Download this project
2. Import the project to Eclipse IDE

# Run the Test
1. Put your web URL in application.properties file
2. Make sure you have the chromedriver match with your machine's chrome version
3. Download chromedriver from this URL https://sites.google.com/chromium.org/driver/downloads and put it in Driver folder
4. Create your feature file, UI constants, and step definition in the provided package and folder
5. To run the automation, right click on the desired feature file and select Run As > Cucumber Feature
